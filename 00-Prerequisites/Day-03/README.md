# Day 03 — Exponents & Logarithms

**Subtitle:** Growth and Reverse Growth  
**Phase:** 0 — Prerequisites  
**Difficulty:** Easy  
**Prerequisites:** Functions (Days 1–2)

## Why this matters

The lesson connects exponents and logarithms to growth rates, probabilities, loss functions, and information theory. AI/ML examples include cross-entropy loss, softmax, learning-rate decay, entropy, and log-probabilities.

## Learning objectives

- Explain exponentiation as repeated multiplication and exponential growth.
- Explain logarithms as asking which power produces a number.
- Recognize base 10, base 2, and natural logarithms (ln).
- Apply basic exponent and logarithm rules.
- Plot exponential and logarithmic curves in Python.
- Describe where logs and exponentials appear in AI/ML.

## Learning flow

Intuition → Real-life examples → Visual comparison → Rules → Worked example → Python plots → AI/ML connection → Practice → Mastery check.
