# Day 04 — Coordinate Geometry

**Subtitle:** The Map Where All Data Lives  
**Phase:** 0 — Prerequisites  
**Difficulty:** Easy  
**Prerequisites:** Functions (Days 1–2), Exponents (Day 3)

## Why this matters

Every data point lives in coordinate space. Coordinate geometry supports feature spaces, distance metrics, scatter plots, and decision boundaries.

## Learning objectives

- Explain the coordinate plane, axes, origin, and ordered pairs.
- Calculate distance and midpoint between two points.
- Calculate slope and interpret the equation y = mx + b geometrically.
- Visualize points, line segments, distance triangles, and midpoints in Python.
- Connect coordinate space and distance to K-nearest neighbors (KNN), clustering, and ML feature spaces.
