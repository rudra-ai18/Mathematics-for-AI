# Day 05 — Scalars & Vectors

**Subtitle:** The Beginning of Linear Algebra  
**Phase:** 1 — Linear Algebra  
**Difficulty:** Easy  
**Prerequisites:** Functions (Days 1–2), Coordinate Geometry (Day 4)

## Why this matters

A scalar is one number; a vector is an ordered list of numbers. Vectors are a basic way to represent data in machine learning.

## Learning objectives

- Explain the difference between scalars and vectors.
- Identify vector components and dimensions.
- Calculate the magnitude (length) of a 2D vector.
- Add and subtract vectors component-wise.
- Multiply a vector by a scalar.
- Visualize vectors as arrows using Python.
- Connect vectors to feature data, word embeddings, neural-network weights, and image pixels.

## Learning flow

Intuition → Real-life examples → Visual intuition → Mathematics → Worked examples → Python visualization → AI/ML connection → Practice → Mastery check.
