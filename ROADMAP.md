# Mathematics for AI — Roadmap

## Goal

Master the mathematics required for AI/ML engineering through:

**Understand → Visualize → Calculate → Code → Apply → Explain**

The goal is to be able to look at an equation in an ML paper and understand what it means, why it is there, and what the model is doing.

## Mastery Rule

A concept is not complete until I can:

- [ ] Explain it in simple words
- [ ] Solve a basic mathematical problem
- [ ] Visualize it
- [ ] Implement it in Python
- [ ] Explain its AI/ML application
- [ ] Explain WHY AI/ML uses it

## Phase 0 — Prerequisites

Arithmetic, fractions, percentages, basic algebra, exponents & logarithms, functions & graphs, coordinate geometry.

## Phase 1 — Linear Algebra

Scalars, vectors, vector operations, dot product, magnitude, angle, projection, matrices, matrix multiplication, transpose, identity, inverse, determinant, rank, vector spaces, basis, span, linear independence, eigenvalues, eigenvectors, SVD.

## Phase 2 — Analytic Geometry

Distance, angles, projections, lines, planes, hyperplanes, and geometric interpretation of ML models.

## Phase 3 — Calculus

Functions, intuitive limits, derivatives, slope, tangent, power rule, chain rule, partial derivatives, gradient, directional derivative, Jacobian, Hessian, and integrals for area/probability.

## Phase 4 — Probability

Experiments, outcomes, events, sample space, conditional probability, independence, Bayes theorem, random variables, expectation, variance, covariance, and core distributions.

## Phase 5 — Statistics

Population vs sample, descriptive statistics, sampling, estimation, MLE, hypothesis testing, confidence intervals, and bias-variance tradeoff.

## Phase 6 — Optimization

Objective/loss/cost functions, minima/maxima, convexity, gradient descent, learning rate, SGD, momentum, Adam, and Lagrange multipliers.

## Phase 7 — Information Theory

Information, entropy, cross-entropy, KL divergence, mutual information.

## Phase 8 — Classical ML Math

Linear regression, logistic regression, PCA, SVM, neural-network forward pass and backpropagation.

## Phase 9 — Modern AI Math

Embeddings, vector spaces, cosine similarity, attention, Transformer matrix multiplication, softmax, cross-entropy, positional encoding, LLMs, RAG, and generative AI.

## Resources

- **Primary:** Mathematics for Machine Learning — Deisenroth, Faisal, Ong
- **Visual intuition:** 3Blue1Brown — Essence of Linear Algebra
- **Practice:** Khan Academy
- **Code bridge:** Python, NumPy, Matplotlib
- **Symbolic math:** SymPy
- **Modern AI:** The Illustrated Transformer + selected papers
- **Deep learning implementations:** PyTorch (Phase 8+)

## Topics intentionally skipped

Trigonometric identities, complex analysis, formal Riemann-sum proofs, advanced integration techniques, abstract algebra, measure theory, and topology unless a later AI/ML need makes them relevant.
