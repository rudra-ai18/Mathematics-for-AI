# Mathematics for AI — Master Roadmap

## Goal

Build mathematical intuition and practical coding skills for AI/ML, from prerequisites to modern AI and LLM foundations.

**Learning loop:** Understand → Visualize → Calculate → Code in VS Code → Connect to AI/ML → Practice → Mastery Check → Update GitHub

## Mastery Rule

A concept is complete only when I can:

- [ ] Explain it in simple words
- [ ] Solve a basic mathematical problem by hand
- [ ] Visualize the concept where useful
- [ ] Implement it in Python and run it in VS Code
- [ ] Explain its AI/ML application
- [ ] Explain why AI/ML uses it
- [ ] Complete the practice and mastery check

## Phase 0 — Prerequisites

Arithmetic review → Algebra → Exponents & Logs → Functions → Coordinate Geometry

## Phase 1 — Linear Algebra

Scalars → Vectors → Vector addition → Dot product → Magnitude → Matrices → Matrix multiplication → Transpose → Identity → Inverse → Determinant → Rank → Vector spaces → Basis → Span → Linear independence → Eigenvalues → Eigenvectors → SVD

## Phase 2 — Analytic Geometry

Distance formula → Projections → Lines → Planes → Hyperplanes → Angles

## Phase 3 — Calculus

Functions → Limits (intuition) → Slope → Derivative → Power rule → Chain rule → Partial derivatives → Gradient → Directional derivative → Jacobian → Hessian → Basic integrals (area/probability only)

## Phase 4 — Probability

Experiments → Sample space → Events → Probability → Conditional probability → Independence → Bayes theorem → Random variables → Expectation → Variance → Covariance → Bernoulli → Binomial → Uniform → Gaussian → Exponential

## Phase 5 — Statistics

Population vs sample → Mean/median/mode → Variance/SD → Sampling → Estimation → Likelihood → MLE → Hypothesis testing → Confidence intervals → Bias-variance tradeoff

## Phase 6 — Optimization

Objective functions → Loss functions → Minima/maxima → Convexity → Gradient → Gradient descent → Learning rate → SGD → Momentum → Adam → Lagrange multipliers

## Phase 7 — Information Theory

Information → Entropy → Cross-entropy → KL divergence → Mutual information

## Phase 8 — Classical ML Math

Linear regression (closed form + gradient descent) → Logistic regression → PCA → SVM → Neural network forward pass → Backpropagation → Training

## Phase 9 — Modern AI Math

Embeddings → Cosine similarity → Attention mechanism → Transformer math → Softmax → Positional encoding → LLM loss → Generative model foundations

## Daily Implementation Workflow

1. Learn the concept and build intuition.
2. Solve a small mathematical example by hand.
3. Visualize it where a graph or diagram adds value.
4. Write and run the Python implementation locally in VS Code.
5. Inspect the output, debug, and explain what the code does.
6. Connect the concept to a real AI/ML use case.
7. Complete practice questions and the mastery check.
8. Update notes and progress documentation.
9. Commit and push tested local changes to GitHub.

## Standard Daily Folder

Use only files needed for each topic; do not create empty or duplicate files.

- `README.md` — objective, outcomes, and navigation
- `notes.md` — intuition, formulas, examples, and AI/ML connection
- `practice.md` — exercises
- `mastery-test.md` — self-check and completion criteria
- `implementation.py` — coding work, authored and run in VS Code

## Suggested Resources

- **Mathematical foundations:** *Mathematics for Machine Learning* — Deisenroth, Faisal, and Ong
- **Visual intuition:** 3Blue1Brown
- **Guided practice:** Khan Academy
- **Numerical computing and visualization:** Python, NumPy, Matplotlib
- **Symbolic mathematics:** SymPy
- **Modern AI:** The Illustrated Transformer and selected technical papers
- **Deep learning implementation:** PyTorch when the roadmap reaches neural networks

## Scope

Prioritize mathematics that directly supports data science, classical machine learning, deep learning, and modern AI. Study advanced or tangential mathematics only when it becomes useful for a defined learning goal.
