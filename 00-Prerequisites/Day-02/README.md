# Day 02 — Functions in AI/ML

**Topic:** Parameterized Functions — How Models Learn to Approximate Functions  
**Phase:** 0 — Prerequisites  
**Difficulty:** Easy  
**Prerequisite:** Day 1 — Functions

## Learning objectives

- Explain why an ML model's function is learned from data.
- Understand the parameterized function f(x) = mx + b.
- Explain the roles of input x, prediction y, slope m, and intercept b.
- Compare predictions with actual values and calculate errors.
- Visualize house-size data and a candidate model line using Python in VS Code.
- Connect the exercise to linear regression, model training, loss, and optimization.

## Learning flow

Intuition → House-price example → Graph → Parameters → Prediction and error → Python implementation → AI/ML connection → Practice → Mastery check.
